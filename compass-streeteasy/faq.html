🔒 資安 / 授權
資安 / 授權
「授權之後，你們能看到我信箱裡所有的信嗎？」
不會。我們在授權前會先幫你設定一個專用標籤（Label），授權後系統只能看到這個標籤底下的信件——也就是 StreetEasy 寄來的那些。其他業務往來、合約、個人信件完全碰不到。
關鍵說法：Label 隔離是技術保護，不是承諾——授權範圍在系統架構層就已鎖定。
資安 / 授權
「Compass IT 不允許第三方工具連信箱怎麼辦？」
這個我們有備案。只要設一個獨立的轉信 Gmail，把 StreetEasy 的信轉寄過去，系統監控那個信箱就好，完全不碰 @compass.com 信箱，IT 那邊也不會有問題。
說明重點：備案方案不會影響客戶日常作業，也不需要 IT 介入。
資安 / 授權
「如果我之後不想用了，怎麼取消授權？」
很簡單，到 Google 帳號設定頁找到對應的應用程式，點一下撤銷就完成了。不需要找我們，自己就能做。
入口網址：myaccount.google.com/permissions
資安 / 授權
「你們會不會把我的客戶資料存起來？」
不會。信件資料流過自動化系統後不會另外儲存，我們也不持有你的帳號密碼。整個帳號和設定都在你手上，我們只是幫你把流程建起來。
強調：帳號永遠歸客戶所有，我方以最小權限協作，建置完成可立即退出。

費用 / 帳號
「這個工具是免費的嗎？後續有沒有月費？」
目前你們的業務量，免費方案就完全夠用了。如果以後詢問量大幅成長，升級方案的費用大概是每個月 $9 美金。這個帳號是你們自己的，我們不從中收取任何平台費用。
現況：每月約 20–25 封，免費方案上限 1,000 次 operations，非常充裕。

帳號由你們自己註冊，綁定你們的付款方式。我們是以「協作者」身份受邀進入幫你建置，建置完成後可以直接退出，帳號完全是你們的。
費用 / 帳號

可以。所有設定都在你們的帳號裡，我們退出之後系統照常運作。交付時我們也會附上操作說明，你們自己就能維護基本的日常調整。
底線訊息：你們不依賴我們也能繼續跑。這是我們交付品質的一部分。
⚙️ 功能 / 效果
功能 / 效果
「自動回覆會讓租客覺得不是真人嗎？」
我們在設計模板的時候會特別注意這一點——語氣自然、有溫度，不會像制式的機器人回覆。通常租客收到後不會特別感覺是自動化的，而且第一封回覆的目的是確認收到、引導對話，後續還是由你們親自跟進。
功能 / 效果
「每封信都會自動回嗎？還是可以選擇性觸發？」
系統只處理 StreetEasy 寄來的詢問信，其他信件完全不影響。如果你們有特殊需求（例如某類物件不要自動回），也可以透過條件設定來篩選。
觸發條件：寄件者 domain 為 email.streeteasy.com，其他信件不會被碰。
功能 / 效果
「如果多個 Agent 同時收到同一個詢問，會重複回覆嗎？」
不會。StreetEasy 只會把信寄給主責的那位 Agent，CC 的人不會觸發自動化，所以天生就不會有重複回覆的問題。
功能 / 效果
「我能自己改回覆內容嗎？不用每次都找你們？」
可以。交付的時候我們會附上一份操作說明，告訴你在哪裡改、怎麼改。模板欄位都有標示清楚，不需要任何技術背景就能自己調整文字。
獨立性：日常維護不需要找我們，這是我們交付的基本標準。
📅 時程 / 流程
時程 / 流程
「多久可以完成？」
一般來說，從確認合約到系統上線大約 5 到 7 個工作天。主要的變數是 Gmail 授權那一步，只要你們這邊配合順利，通常不會拖太久。
時程關鍵：客戶完成帳號設定的速度，是整個流程最大的變數。
時程 / 流程
「我需要做哪些事？」
你們主要需要做三件事：註冊一個帳號、在 Gmail 裡設定一個標籤、然後點一下授權連結。我們會提供逐步的說明文件，照著做大概 15 到 20 分鐘可以完成。
三步驟：① 註冊帳號 ② 設定 Label ③ OAuth 授權
時程 / 流程
「先付錢再做還是做完再付？」
我們的標準付款條件是簽約後先付 50% 訂金，系統驗收通過後再付尾款。這樣對雙方都有保障——你們確認做得到再付全款，我們也確保有基本保障才開始建置。
付款結構：50% 簽約後 + 50% 驗收後
